# BorrowGlyph（借字）

做设计时，难免遇到选用的字体恰好缺字的情况，

简单的字还好。比如「珣」，大概很容易想到可以对「珍」和「询」各取一半；但遇到「髮」这种字，就很难立刻想到该去哪里截部件。

（做这个小工具的源头就是发现有个繁体字体默认把「发」转换为「發」但我需要「白髮」，一时抓耳挠腮……）

**BorrowGlyph 用来帮你找这些“可以借的字”。**

输入缺失的汉字，它会按结构拆开，并优先寻找：

- 部件位置和目标字相近的常见字
- 可以直接拿来用的独体部件
- 当前字体已经收录的字
- 找不到整块时，还可以继续向下拆

例如「髮」的下部「犮」如果没有合适的整块来源，可以进一步拆成「友 + 丶」（当前这个拆解方案是一个人工补充，之后随着使用或许会补充更多不能由规则自行判断的方案）；其中「友」又会优先寻找像「爱」这样本来就在上下结构下部的字形，而不是简单拿独体「友」硬压扁。

在线使用：  
https://eglantine-shell.github.io/BorrowGlyph/

## BorrowGlyph 怎么选字

BorrowGlyph 在检索“哪些字含有这个部件”时，首先关心的是，**哪个字里的这一块，拿过来以后改得最少。** 因此通常会优先考虑部件所在的位置。

例如目标需要的是一个位于上下结构下部的「友」，则 `爱` 里的「友」通常会比 `友` 本身更适合，因为前者本来就已经压缩成下部字形，可以更好地避免拼合时变形。

常用程度、本字是否可直接使用、当前字体是否收录等因素也会参与排序。

## 复杂字怎么办

如果一个部件本身找不到合适来源，BorrowGlyph 会尝试继续拆分。

大部分拆分来自 IDS 汉字结构数据，但设计拼字和文字学拆字并不是一回事。有些结构虽然不会直接写进 IDS，实际设计时却很好用，因此项目也允许维护少量人工视觉特例，如目前已有：`犮 → 友 + 丶` 。

人工特例只在正常候选不够合适时启用，不会无条件覆盖更好的整块来源。

## 当前版本

目前已经支持单字查询、递归拆分、本字候选、繁简筛选、字体本地读取，以及无法在当前系统正常显示的候选过滤。

BorrowGlyph 只负责帮你找到更合适的“材料”。最终拼合仍需要自行设计完成；不同字体的具体字形需要根据实际情况调整。

## 本地运行

需要 Node.js 18+。

```bash
npm install
npm run dev
```

首次运行会从公开数据源生成 `public/data.json`。完整结构数据作为独立静态资源加载；仓库中保留了一份小型回退数据，因此刷新远程数据失败时仍可构建。

单独刷新数据：

```bash
npm run data
```

回归测试：

```bash
npm test
```

生产构建会先刷新数据并运行回归测试：

```bash
npm run build
```

当前回归测试覆盖了几类已经确认的重要行为，包括：

- 「爱」能够作为「友」的下部 donor。
- 独体「友」能够作为本字 donor。
- 「犮」能够保留来自不同结构位置的 donor。
- 「發」能够保留复合下部供递归拆分。
- 简体、繁体、繁简共用候选不会因为统一截断而互相挤掉。

## 数据来源

结构数据使用 [hfhchan/ids](https://github.com/hfhchan/ids) 的 IDS release（MIT License）。

常用度基础使用 [jaywcjlove/table-of-general-standard-chinese-characters](https://github.com/jaywcjlove/table-of-general-standard-chinese-characters) 整理的《通用规范汉字表》数据（MIT License）。一级、二级、三级字依次获得更高排序；繁体字会尽可能继承对应规范简体字的常用等级。

繁简属性也基于该项目提供的繁简转换数据，用于「不限 / 简体 / 繁体」候选筛选。

## 当前边界

BorrowGlyph 解决的是「**哪个字更适合借来切部件**」，不是自动完成最终字形设计。

IDS 描述的是结构关系，不能保证两个字在某一款字体里的局部轮廓完全一致；实际拼合仍可能需要缩放、位移和节点修整。对于 IDS 无法合理表达的视觉关系，也仍需要少量人工维护的设计特例。

系统字形显示能力取决于用户设备实际安装的字体；当前版本会过滤无法正常显示的 donor，而不是额外下载大字集 webfont。

## 部署

仓库包含 GitHub Pages Actions workflow。启用仓库的 Pages（Source 选择 **GitHub Actions**）后，推送到 `main` 会自动刷新数据、运行回归测试、构建并部署。
